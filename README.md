# IP Room - Nepal's Student & Renter Room Marketplace

Nepal's premier marketplace connecting students and renters with room owners across all 77 districts, featuring localized search, Khalti/eSewa booking, and digital tenancy contracts.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Features
- **Student-First Room Discovery**: Campus proximity matching, water schedule alerts, budget filters.
- **Supabase Authentication & Role Verification**: Google OAuth & Email/Password with admin verification.
- **Tenancy Contracts & Local Payments**: Khalti and eSewa digital advance booking.
